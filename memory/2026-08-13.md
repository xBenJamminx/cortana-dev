## Hungryroot cronjob failure — diagnosed and partly fixed

**Trigger:** Cronjob `18d99cc38272` ("Midweek Hungryroot plan check") reported blocked:
`python3: can't open file '/root/cortana/scripts/hungryroot_api.py': [Errno 13] Permission denied`

**Real cause (not a permission bug):**
- `hungryroot_api.py` does not exist anywhere in cortana-dev. Zero mentions repo-wide.
- `/root/cortana` does not exist in the remote session container at all; the repo clone
  lives at `/home/user/cortana-dev`.
- Python raises EACCES both for an unreadable file and for an *unsearchable parent* —
  `/root` is `drwx------`, so a non-root process gets "Permission denied" on
  `/root/anything` whether or not the file is there. The error text was a red herring.

**Shipped** on `claude/hungryroot-api-permission-6ndclp` (commit `8f380bf`):

  `/root/cortana`, `~/clawd`, `/root/clawd`; failure report distinguishes not-found /
  unreadable-file / unsearchable-parent. Both branches tested (incl. as uid 65534).
- `scripts/cortana-run.py` — run scripts by name, not absolute server path. Exit 127 + diagnosis.
- `docs/cron-script-paths.md`, CLAUDE.md task-router entry.
